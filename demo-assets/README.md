# Demo assets

- `demo_claim_county_budget.txt` — demo text claim (mixed English/Sheng) about the
  real Nairobi County KSh 49.27B FY 2025/26 budget. The core figures are real and
  verifiable — used to demonstrate a "Verified" verdict with nuance.
- `fake_tender_notice_simulated.png` — **simulated** fake tender notice created for
  this project (`make_tender_notice.py`) to demonstrate a "False / scam pattern"
  verdict. It is NOT a real document, and deliberately contains classic red flags
  (upfront M-Pesa "registration fee", personal contact, urgency). The scam pattern
  itself is real — e.g. the Tana Water Works Development Agency's public warning
  about fake procurement scams.
